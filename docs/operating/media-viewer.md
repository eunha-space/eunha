Image viewer
============

Selecting an image attached to a post opens a full-screen viewer inside the web
client. Moderation post previews use the same viewer. Image descriptions remain
visible below the image, and the picture fits the available screen without
cropping. Sensitive post attachments must be revealed before opening them.

For posts with several images, use **Previous** and **Next**, the left and right
arrow keys, or swipe horizontally on a phone. Video, animated video and audio
attachments retain their inline players and are not included in the image
sequence. **View image at original size** shows the full-resolution image in a
scrollable area; **Fit image to screen** returns to the fitted view. Swiping
between images is disabled while viewing original size so scrolling can pan the
picture.

Close the viewer with its close button or Escape. Keyboard focus returns to the
image that opened it. **Open original image in a new tab** remains an explicit
action, including when an image fails to load.
