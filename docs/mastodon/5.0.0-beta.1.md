Outstanding from 5.0.0-beta.1
=============================

Eunha tracks Mastodon 5.0.0-beta.1, which also takes in the security fixes of
4.7.4 and 4.7.5. The schema is adopted whole. Each feature below is not in
Eunha, and has an entry in [*divergences.toml*](./divergences.md):

From earlier releases, and what an operator should check before moving from
Mastodon:

 -  **Media player pages**, and so Twitter's player cards.
 -  **`tootctl`'s `ip_blocks`, `email_domain_blocks`,
    `canonical_email_blocks` and `upgrade`**. The admin API has the blocks.
 -  **Web client pages** for lists, filters, followed hashtags, scheduled
    posts, collections, personal domain blocks, the notification policy,
    private notes and Web Push. The API serves them to other clients.

Left out on purpose, and not planned:

 -  **Single sign-on and directory sign-in**: OIDC, SAML, CAS, LDAP and PAM.
    **An instance that depends on one cannot drop Eunha in.**
 -  **CAPTCHA** at sign-up.


Before upgrading
----------------

The migration can be applied only once, and it drops a column.

 -  **`accounts.private_key` is dropped.** `eunha migrate` first moves any local
    keys still in it to `keypairs`, encrypted. Migration 039 then refuses to
    drop the column if any are left. This cannot be undone, so run
    [`eunha rehearse-migration`](../operating/migrations.md) against a copy.

 -  **The ActiveRecord encryption secrets are now required.** Upstream has no
    fallback any more, and neither has Eunha: an instance without
    `[active_record_encryption]` can no longer sign, so it fails to start. See
    [signing keys](./signing-keys.md).

 -  **`authorized_fetch` now defaults to `actors`.** Unset, an unsigned fetch of
    an actor gets a 401. Set it to `none` to keep the old behaviour; see
    [the settings](../operating/administration.md#what-the-settings-drive).

 -  **A member's own boosts leave their home feed by default**, and own posts
    stay. See [accounts](../operating/accounts.md#boosts-in-timelines).


What changed and was followed
-----------------------------

Security fixes from 4.7.4 and 4.7.5:

 -  A fetched ActivityPub document has to name the address it was served from,
    and terminal fetches follow no redirects.
 -  An actor's key has to be on the actor's own host, and its `inbox` has to be
    present.
 -  JSON-LD documents have a budget of 1000 nodes, checked on the inbox in
    [ojak].
 -  HEIC, HEIF and AVIF uploads are refused.
 -  Revoking a remote collection's item removes it locally.

Added in 5.0:

 -  **Sign-in tokens**: a long-inactive account is asked for a code sent by
    mail. See
    [accounts](../operating/accounts.md#a-security-code-after-a-long-absence).
 -  **Sign-up through an app**: `prompt=create` and `prompt=login` on
    `/oauth/authorize`, with `prompt_values_supported` in the metadata. See
    [the OAuth server](../operating/accounts.md#the-oauth-server).
    `POST /api/v1/accounts` carries `Deprecation: @1790812800`, for 2026-10-01.
 -  **Postponed confirmation mail**: `postpone_confirmation_emails`. See
    [signing up](../operating/accounts.md#signing-up).
 -  **FASP capability activation**, kept per capability.
 -  **The credential account's `state`**, and
    `verify_credentials?allow_nonfunctional=true` to read it.
 -  **Own posts and boosts in the home feed**, `display_own_posts` and
    `display_own_boosts`, and `exclude_direct`, `exclude_reblogs`,
    `exclude_quotes` and `exclude_replies` on `GET /api/v1/timelines/home`.
 -  **Links** are found as [UTS #58] says. See
    [formatting](./formatting.md#local-text).
 -  **Warning presets** have an `action_category`.
 -  **`source[spoiler_field]`**, `disable_announcement_reactions`,
    `registrations.oauth` on the instance, the `optIn*` nodeinfo metadata, and
    `ref` on following, counted in `activity:feature_usage:follow:<day>`.
 -  A status search with nothing but operators answers 400.
 -  `/@user@domain` paths that do not resolve answer 404.
 -  `Scheduler::RepairRemoteCollectionsScheduler` and
    `tootctl accounts fix-duplicates` are gone, as upstream removed them.

[ojak]: https://github.com/eunha-space/ojak
[UTS #58]: https://www.unicode.org/reports/tr58/


New in this release
-------------------

 -  **Moderation list subscriptions**, an experimental feature behind
    `experimental_features = ["moderation_subscriptions"]`: see
    [Moderation subscriptions](../operating/moderation.md#moderation-subscriptions).
    The beta's code for applying a suggestion cannot run as released, so Eunha
    implements what it evidently means; `moderation-lists-fixes-beta-bugs`
    records where, for review against the next release.

 -  **Account deletion reach tracking**: new local accounts record the inbox
    hosts of signed actor fetches, allowing narrower deletion delivery.
    See [actor reach](./serving.md#account-deletion-reach).

 -  **Web composer and appearance**: the composer docks over the feed and
    keeps its draft when minimized or when navigating. The post settings menu
    separates content warnings, sensitive media and quote permissions.
    Members can open the content warning field by default, choose a color
    palette, follow hashtags from posts or tag timelines, and control boosts
    from followed accounts from the post menu.

 -  **Server checks**: see
    [Server health](../operating/administration.md#server-health).
